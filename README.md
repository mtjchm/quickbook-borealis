**Quickbook** is a web-based application designed to simplify reservation management for companies. Customers can easily submit their requests, and the system takes care of the rest. Businesses gain a clear and efficient interface to manage incoming reservations without the need for installation or technical setup.

##  Key Features

-  Web-based – no installation required
-  Simple, intuitive and user friendly UI
-  Businesses manage reservations through an admin dashboard
-  Secure login for company administrators

##  For Businesses

Once logged in, administrators can:

- View all incoming reservations
- Access detailed information (time, place, service type, customer info)
- Filter and manage requests efficiently

##  For Customers

Customers simply:

1. Fill out a short request form
2. Submit their reservation
3. Let Quickbook handle the processing

##  Usage

Quickbook is designed is:

-  Orgasnised and structured reservations
- Designed to save time and simplify your booking process

##  Technologies

- Frontend: React
- Backend: Typescript
- Database: PostgreSQL
- Deployment: Azure
